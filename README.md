# Smart Door Lock Using RFID, ESP32 and KiwisIoT

## About the Project

The **Smart Door Lock Using RFID** is an IoT-based security project designed to provide convenient and controlled door access using RFID technology.

Using an ESP32 microcontroller, an RFID reader, and an electronic door lock, the system identifies authorized RFID cards or tags and controls the door locking mechanism. Access status can also be shared with the KiwisIoT platform through Wi-Fi, allowing users to monitor door access activity remotely.

This project demonstrates how RFID technology and KiwisIoT can be integrated to develop smart access control and home security solutions.
